# Фотографии Северстали

Из 15 файлов `resources/severstal/templates` извлечены **99 фотографий**. PNG и JPEG сохранены побайтно, без пересжатия, изменения размеров и кадрирования. Одинаковые исходные байты объединены; разные исходные кадры, размеры и обработки одного сюжета оставлены отдельно.

`catalog.json` содержит русские названия, описания, теги, размеры, SHA-256 и все исходные использования (PPTX, номер слайда, XML-часть, ID и имя фигуры). Модель выбирает `images[].id`; путь к файлу указан в `file`. Изображения не подтверждают личности изображенных сотрудников; портреты подписаны по внешнему виду.

Два исходника JPEG XR из слоя эффектов PowerPoint сохранены в `originals/` и связаны с соответствующими PNG через `embedded_originals[].photo_id`. Для обычной вставки используйте PNG из `images`.

В `output/assets/photos/severstal/` создаются `contact_sheet_*.jpg` — визуальный каталог — и `extraction_report.json`, который перечисляет исключенные нефотографические media: иконки, логотипы, цифры, фирменную графику, рамки устройств и образцы диаграмм. Эти объекты остаются в первоисточниках; библиотека иконок находится в `assets/icons/severstal`.

Повторное извлечение из корня проекта: `python scripts/extract_severstal_photos.py`. Семантическая классификация хранится в `scripts/data/severstal_photo_metadata.json`; неизвестный SHA-256 останавливает скрипт, чтобы новые фото не были молча исключены.
