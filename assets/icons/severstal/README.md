# Иконки «Северсталь»

Библиотека извлечена из `resources/severstal/templates/Severstal_Icons.pptx`.
30 тематических папок повторяют названия групп исходника. Продолжения групп
«Продукция», «Безопасность труда» и «Навигация» объединены в соответствующих
папках; номера всех 33 исходных страниц сохранены в каталоге.

`catalog.json` — каталог для модели: `asset_id`, русское `name`, `description`,
`tags`, `group_id`, пути к SVG и PNG и точная ссылка на исходную страницу и фигуры.
Файлы названы по смыслу пиктограммы; имена файлов записаны латиницей.
Синее и белое исполнения имеют самостоятельные идентификаторы. Одинаковые
изображения в разных исходных тематических группах сохранены в этих группах.

Всего сохранены 1364 исходных графических элемента. Для выбора доступны
1362 исполнения пиктограмм. Две красные пометки «6» и «7» на странице
«Продукция» сохранены для сверки с первоисточником и имеют `selectable: false`;
модель не должна выбирать их в качестве иконок.

SVG сохраняют исходную графику. 576 встроенных SVG скопированы без изменения
байтов; остальные файлы собраны из исходных контуров DrawingML и встроенных
изображений. Из 1364 SVG 1323 содержат векторную графику, а 41 включает исходные
растровые изображения, преимущественно из группы «Обучение персонала».
Растровые иконки не перерисовывались; исходные пиксели встроены в SVG без потерь.
Поле `is_vector` позволяет различать эти случаи.

Каждому SVG соответствует прозрачный PNG для вставки и предпросмотра,
отрисованный с размером до 256 пикселей по стороне. При масштабировании
предпочитайте SVG. Папка `output/assets/icons/severstal/contact_sheets/` содержит визуальные указатели по
исходным страницам: номера соответствуют `source.index` каталога. Серый фон
контактных листов помогает увидеть белые иконки; он не добавлен в сами SVG/PNG.
Синие плашки, которые были частью исходного изображения, сохранены.

В первоисточнике встречаются белые SVG на белом фоне. Такие SVG остаются
белыми и подходят для цветной подложки. Их содержание видно на контактных
листах, даже если на исходном слайде изображение сливается с фоном.

Выбор модели: сначала группа, затем название и теги, затем `asset_id`.
Проверяйте `selectable`, сохраняйте пропорции и выбирайте цветовое исполнение
с учетом подложки. Не подменяйте иконку похожим рисунком из внешней библиотеки.

Воспроизведение из корня проекта:

```powershell
python scripts/extract_severstal_icons.py --render
```

Пути указаны относительно корня репозитория. Контактные листы и инвентаризация
`output/assets/icons/severstal/source_inventory.json` создаются при извлечении и
исключены из Git вместе с `output/`. Для сборки презентаций достаточно файлов
библиотеки и `catalog.json` в `assets/icons/severstal/`.

Для PNG необходим дополнительный пакет `resvg_py`; SVG извлекаются с обычными
зависимостями проекта. Скрипт использует проверенные русские наименования
из `scripts/data/severstal_icon_names*.json`, не обращается к внешней модели и не
изменяет исходный PowerPoint. Запуск без `--render` создает только SVG и каталог.

Проверка целостности:

```powershell
python -m unittest discover -s tests -p test_severstal_icons.py -v
```
