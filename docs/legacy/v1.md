# Версия 1.x: совместимость и воспроизведение

Активный шаблон проекта — 2.0. Эта инструкция относится к прежнему генераторному шаблону **1.2**: 14 типов содержания, 31 оформление и совместимость с JSON версий 1.0–1.2. Старые файлы перенесены в папки `legacy`, их формат сохранён.

## Файлы

Все пути в командах отсчитываются от корня репозитория.

| Путь | Назначение |
| --- | --- |
| `templates/legacy/corporate_base.pptx` | Подготовленный шаблон с одним master, 31 layout и без слайдов |
| `templates/legacy/template_manifest.json` | Контракт полей, геометрия и варианты |
| `examples/legacy/presentation.json` | Шесть базовых типов, версия 1.0 |
| `examples/legacy/variety.json` | Все 14 типов с оформлением `default` |
| `examples/legacy/variants.json` | Все 31 вариант оформления |
| `assets/images/` | Проверенная библиотека шести фотографий и каталог для версии 1.x |
| `resources/severstal/severstal-template-v29.pptx` | Исходная корпоративная библиотека |
| `scripts/legacy/` | Подготовка, построение вариантов и аудит старого шаблона |

Установка Python и запуск описаны в [основном README](../../README.md). Происхождение оформления — в [карте вариантов](brand-variants.md), устройство шаблона — в [инструкции подготовки](template-preparation.md).

## Проверка и сборка

CLI по умолчанию использует версию 2.0. Для старых JSON всегда передавайте оба пути:

```powershell
$legacy = @('--template', 'templates/legacy/corporate_base.pptx', '--manifest', 'templates/legacy/template_manifest.json')
.\run.ps1 inspect-template @legacy
.\run.ps1 validate examples/legacy/variants.json @legacy
.\run.ps1 build examples/legacy/variants.json @legacy
.\run.ps1 build examples/legacy/variety.json @legacy
.\run.ps1 build examples/legacy/presentation.json @legacy --output output/demo.pptx
```

Результаты первых двух сборок: `output/variants.pptx` и `output/variety.pptx`; рядом создаются `.report.json`. Выходные файлы не хранятся в Git. Если в JSON нет `variant_id`, используется композиция `default`.

Для `draft` передавайте те же `@legacy` вместе с настройками LLM и документами по инструкции из README. API-ключ остаётся в окружении; файлы локальных настроек исключены из Git.

## Повторная подготовка

Используйте Python с установленными зависимостями проекта:

```powershell
$env:PYTHONPATH = (Join-Path $PWD 'src')
python scripts/legacy/prepare_template.py
python scripts/legacy/prepare_template.py --extract-images
python scripts/legacy/audit_template.py
python scripts/legacy/make_variant_example.py
python -m unittest discover -s tests
```

Подготовка обновляет версионируемые файлы в `templates/legacy/`; `--extract-images` восстанавливает фотографии в `assets/images/`, а контактный лист пишет в `output/assets/images/selection_preview.jpg`. Скрипт `make_variant_example.py` обновляет `examples/legacy/variants.json`. Аудит выводит JSON в стандартный вывод; для сохранения используйте перенаправление в `output/`.

Для проверки конкретного PPTX через установленный настольный PowerPoint:

```powershell
.\scripts\verify_powerpoint.ps1 -InputFile output/variants.pptx -OutputDirectory output/variants-powerpoint
```

Скрипт сохраняет PDF, PNG слайдов и `powerpoint-report.json`. Структурная проверка и оценка текстовых рамок требуют последующего визуального просмотра презентации.
