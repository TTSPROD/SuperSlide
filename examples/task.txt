Подготовь демонстрационную презентацию на русском языке по приложенному
файлу source.txt. Аудитория — участники условной внутренней рабочей встречи.

Нужно шесть слайдов:
1. title_slide: название, подзаголовок с пометкой о вымышленных данных,
   автор и дата из исходного материала.
2. bullet_list: краткое описание демонстрационного сценария.
3. two_columns: действия команды и критерии готовности.
4. quote: демонстрационная цитата с указанием вымышленного автора.
5. table: значения компании и рыночного ориентира по четырём кварталам.
6. bar_chart: те же данные по кварталам; роль ряда компании — company,
   роль рыночного ориентира — comparison.

Используй только сведения из приложенного документа. Не добавляй реальные
компании, имена, факты и показатели. На обложке и в заметках к каждому
слайду явно отметь: «Демонстрационный пример. Все данные вымышлены».
Числа таблицы и диаграммы должны точно совпадать с документом.
Добавь ссылки source_refs на предоставленные фрагменты источника.
Верни презентацию в JSON по схеме, переданной системой.
